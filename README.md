# Sales Data Analysis using SQL 📊

Welcome to my SQL data analysis project! This repository contains a complete SQL script that sets up a mock database (`analytics_db`) and performs various data manipulation and exploration tasks. 

I created this project to practice and demonstrate fundamental database management and analytical querying skills using MySQL.

## 🛠️ Tech Stack
* **Database Management System:** MySQL
* **Concepts Covered:** DDL, DML, Data Aggregation, Filtering, Sorting, and SQL Joins.

## 📝 Project Overview
The script (`analytics_db.sql`) is divided into logical steps to simulate a real-world data extraction and analysis workflow. Here is what the project covers:

1. **Database & Table Setup:** Created a structured `sales` table and inserted mock data for 20 orders.
2. **Basic Data Retrieval:** Used `SELECT` statements to pull specific columns like products and sales amounts.
3. **Filtering & Sorting:** Applied `WHERE` clauses to filter data by region/product and `ORDER BY` to sort records logically.
4. **Data Aggregation:** Utilized aggregate functions (`SUM`, `COUNT`) to find total sales and order volumes.
5. **Grouping Data:** Grouped data by regions and products using `GROUP BY` to see performance metrics.
6. **Relational Database Concepts:** Created a second table named `products` (mapping products to categories).
7. **SQL Joins:** Used `JOIN` operations to merge the `sales` and `products` tables and extract category-wise insights.
8. **Dashboard-Style Queries:** Wrote advanced queries to identify the top-selling products and total revenue per category.

## 🚀 How to Run
1. Clone this repository to your local machine.
2. Open your preferred SQL IDE (e.g., MySQL Workbench, VS Code with SQL extension, or phpMyAdmin).
3. Open the `analytics_db.sql` file.
4. Execute the script from top to bottom to create the database, insert the data, and view the query results.
